# Outils Batismart

Outils web pour l'énergétique du bâtiment (CECB, PEIK, SIA 380/1).

Site : https://rom2297.github.io/Outils-batismart/

- **Métré 3D** (`metre3d/`), v24 : dimensions d'enveloppe depuis swissBUILDINGS3D.
- **IsoBase CH** (`isobase/`), v15 : base d'isolants suisses, comparateur et ThermoPlan (U cible, coupe, exports PDF/.usai).
- **Offres batismart** (`offres/`), v22 : génération des offres CECB et prestations énergétiques.
- **PDF Infinity** (`pdf-infinity/`), v2 : outils PDF (fusion, division, compression, OCR, signature…) sans plafond de pages.
